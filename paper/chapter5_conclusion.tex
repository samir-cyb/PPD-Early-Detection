% --------------------------------------------------------
\section{Summary of Work}
\label{ch5-sec-summary}
% --------------------------------------------------------

This thesis built a leakage-free machine learning framework for predicting postpartum depression (PPD) risk in Bangladeshi mothers.
The central problem was that most existing PPD prediction studies use EPDS or PHQ-9 questionnaire answers as model inputs and then predict a label computed from those same answers.
This is data leakage.
It produces unrealistically high accuracy numbers that do not reflect real clinical use.

This thesis removed all 23 EPDS and PHQ-9 columns from the input feature set before any model was trained.
The remaining 108 features (demographic, economic, family, pregnancy, neonatal, and prior mental health history) were used to predict three targets: PPD\_binary (EPDS $\geq 13$), EPDS Result (three-class ordinal severity), and PHQ9 Result (five-class ordinal severity).

Four composite risk indices were engineered from groups of related raw features.
Each index combined its sub-features using chi-square association weights.
The four indices are: Economic Stability Index (ESI), Social and Family Support Index (SSI), Maternal Mental Health Risk Index (MHRI), and Neonatal and Delivery Stress Index (NSI).
All four were statistically validated before being added to the feature set.

Five model families were trained: Logistic Regression, Random Forest, XGBoost, LightGBM, and CatBoost.
A three-arm ablation study compared raw features alone (Arm~A), raw features plus composite indices (Arm~B), and a leakage-safe selected feature subset plus composite indices (Arm~C).
Random Forest on Arm~B was adopted as the final model for PPD\_binary and EPDS Result.
Linear Regression with clinical threshold mapping was adopted for PHQ9 Result.

Explainability was analysed from five angles: global SHAP importance, Arm~A vs Arm~B SHAP comparison, SHAP interaction heatmap, unsupervised cluster validation, and error analysis.
Six robustness experiments were run to check that each design choice held up under alternative settings.

\section{Answers to the Research Objectives}
\label{ch5-sec-objectives}
% --------------------------------------------------------

Chapter~\ref{ch:introduction} stated six objectives.
This section answers each one in turn.

\textbf{Objective 1: Leakage-free pipeline.}
The pipeline excluded all 23 EPDS and PHQ-9 columns at the data-loading stage, before any feature engineering or model training.
No information about the depression label was available to any input feature.
The honest holdout AUC for PPD\_binary is 0.826.

\textbf{Objective 2: Four composite risk indices.}
ESI, SSI, MHRI, and NSI were designed, direction-verified, and chi-square validated.
Every index showed a statistically significant association with all three targets ($p < 0.01$).
All four indices appear in the SHAP top-10 list for every target.

\textbf{Objective 3: Ablation study.}
The three-arm ablation showed that adding composite indices (Arm~B) improved PPD\_binary holdout F1 from 0.756 to 0.762 over raw features alone (Arm~A).
Paired $t$-tests showed the improvement was consistent but not statistically significant at $p = 0.05$ with the available sample size ($n = 800$).
Repeated $5 \times 5$ cross-validation confirmed that the composite effect is real for EPDS Result with XGBoost ($p = 0.0008$) and PHQ9 Result with LightGBM ($p = 0.002$).

\textbf{Objective 4: Multi-angle explainability.}
Five separate explainability analyses were completed.
The strongest raw predictor across all three targets is ``Angry after latest childbirth.''
All four composite indices appear in every SHAP top-10 list.
Unsupervised K-Means clustering produced a 3.6$\times$ PPD prevalence gap between clusters ($\chi^2$ $p = 3.73 \times 10^{-28}$) without ever seeing the depression label.
Error analysis showed that false-negative mothers have atypically low MHRI scores, which suggests they appear healthier by composite profile than they are by EPDS score.

\textbf{Objective 5: Ordinal-aware modeling.}
The Quadratic Weighted Kappa (QWK) metric was applied to both ordinal targets.
For PHQ9 Result, Linear Regression on the continuous score followed by clinical threshold mapping outperformed all direct classifiers (F1-macro $0.329 \to 0.426$, QWK $0.548 \to 0.602$).
This result shows that treating the ordinal structure correctly matters more than the choice of classifier.

\textbf{Objective 6: Explainability–accuracy trade-off.}
The Stacking Ensemble scored 0.029 higher holdout F1 than Random Forest on PPD\_binary.
McNemar's test returned $\chi^2 = 1.45$, $p = 0.228$.
A bootstrap confidence interval test returned $p = 0.074$.
Neither test found a statistically significant advantage for the Stacking Ensemble.
Random Forest was adopted because \texttt{shap.TreeExplainer} gives exact Shapley values for a single tree ensemble.
Explaining a four-model stacking ensemble requires a slower, approximate method.

\section{Contributions}
\label{ch5-sec-contributions}
% --------------------------------------------------------

This thesis makes the following contributions to the PPD prediction literature.

\textbf{Contribution 1: First large-scale leakage-free PPD study for Bangladesh.}
The $n = 800$ Bangladeshi dataset used here is the largest published leakage-free PPD prediction study for this population.
Earlier Bangladeshi studies either used smaller samples or included EPDS/PHQ-9 items as inputs.

\textbf{Contribution 2: Chi-square weighted composite risk index framework.}
The four composite indices (ESI, SSI, MHRI, NSI) reduce over 100 raw survey columns into four clinically interpretable domain scores.
The weighting procedure is transparent, reproducible, and grounded in chi-square statistics rather than subjective scoring.

\textbf{Contribution 3: A clinically actionable threshold system.}
Three operating points are documented: Default (0.500, recall 70.0\%), Max-F1 (0.407, recall 78.6\%), and Screening (0.303, recall 85.7\%).
A deployment team can select the threshold that matches their clinical context without retraining the model.

\textbf{Contribution 4: Composite-space unsupervised cluster triage.}
The three-cluster framework, derived entirely from composite index scores without the PPD label, maps directly to a three-tier clinical workflow.
A community health worker can assign a mother to a risk tier using only four domain scores.

\textbf{Contribution 5: Honest comparison with leakage-affected literature.}
This thesis explicitly names and compares against studies reporting near-perfect accuracy (Nasim et al.\ 99\%, Sreeji and Shirley 99\%, Zohora 99.7\%) and shows that leakage explains the gap.
This comparison is missing from most published studies in this area.

\textbf{Contribution 6: Reproducible open pipeline.}
All code is organised into numbered scripts (01 through 23).
Every figure, table, and experiment result in this thesis can be regenerated from the raw data file by running the scripts in order.

\section{Limitations}
\label{ch5-sec-limitations}
% --------------------------------------------------------

This thesis has four limitations.

\textbf{Limitation 1: Single-site, cross-sectional sample.}
All 800 mothers were recruited from one hospital setting.
The model has not been tested on mothers from rural areas, other hospitals, or other time periods.
A cross-sectional design means that risk factors were measured only at one point in time.
Changes in a mother's situation after the initial survey are not captured.

\textbf{Limitation 2: Self-reported survey data.}
All input features come from self-reported questionnaire answers.
The abuse paradox in this thesis (Section~\ref{ch4-subsec-abuse}) illustrates how a survey answer can differ from clinical reality.
Socially sensitive questions are particularly vulnerable to under-reporting in South Asian populations.

\textbf{Limitation 3: Screening label, not clinical diagnosis.}
The PPD\_binary label is derived from the EPDS cut-off of $\geq 13$.
EPDS is a validated screening instrument, not a formal clinical diagnosis.
A clinician-confirmed diagnosis would be a more rigorous ground truth.

\textbf{Limitation 4: Statistical power for ablation.}
With $n = 800$, paired $t$-tests had limited power to detect small composite index effects at $p < 0.05$.
Repeated cross-validation confirmed effects in some model-target combinations.
A larger dataset would allow cleaner separation between the three arms.

\section{Future Work}
\label{ch5-sec-future}
% --------------------------------------------------------

Several directions are open for future work.

\textbf{Multi-site and longitudinal data collection.}
Recruiting mothers from multiple hospitals across urban and rural Bangladesh would improve generalizability.
A longitudinal design, collecting data at multiple time points after childbirth, would allow the model to track how risk changes over time.

\textbf{Clinical diagnosis as the label.}
Replacing the EPDS cut-off label with a clinician-confirmed psychiatric diagnosis would produce a more rigorous prediction target.
This would require a follow-up clinical assessment for every recruited mother.

\textbf{Bengali-language deployment tool.}
A mobile or web application that accepts structured interview answers in Bengali and outputs a risk score and cluster assignment would make this framework directly usable by community health workers in Bangladesh.
The five-item triage checklist identified in Chapter~\ref{ch:results} is short enough to fit a two-minute structured conversation before any formal screening tool is applied.

\textbf{Extending the composite framework.}
The current four indices cover economic, social, mental health, and delivery-related domains.
Additional domains could be included, such as nutrition, physical health history, and healthcare access.
Each new domain would follow the same chi-square weighting and direction-verification procedure used in this thesis.

\textbf{Larger sample and transfer learning.}
A larger Bangladeshi dataset would allow training of a fine-tuned language model on free-text interview notes, which are richer than structured survey answers.
Transfer learning from larger South Asian mental health datasets would be another direction.

\textbf{Prospective validation.}
The ultimate test of a clinical prediction model is a prospective study in which the model is deployed in a real clinic and its predictions are compared against subsequent clinical assessments.
This thesis provides the foundation — a validated, explainable, leakage-free model — that such a prospective study would need.

\section{Closing Remarks}
\label{ch5-sec-closing}
% --------------------------------------------------------

Postpartum depression is a serious but under-screened condition in Bangladesh.
Machine learning can help, but only if the models are built and evaluated honestly.
This thesis shows that a genuinely leakage-free model can achieve AUC 0.826 on a Bangladeshi PPD dataset.
This is competitive with the best international leakage-free studies and far below the misleading near-perfect numbers produced by leakage-affected approaches.

The composite risk index framework makes the model's reasoning clinically interpretable.
SHAP analysis identifies the same five risk domains consistently across all three depression targets.
The unsupervised cluster structure confirms that these domain scores capture real, depression-related variation without any label supervision.

The honest AUC is not a weakness of this thesis.
It is the point.
A model that achieves 0.826 AUC by genuinely predicting depression from pre-screening information is far more useful to a clinician than a model that achieves 99\% accuracy by asking the same questions twice.
