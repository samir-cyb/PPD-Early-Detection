\section{Overview}
\label{ch3-sec-intro}

This chapter describes the full methodology used in this thesis step by step. The goal is to predict postpartum depression (PPD) risk in Bangladeshi mothers by identifying the most informative subset of EPDS and PHQ-9 questionnaire items through principled feature selection, comparing 15 machine learning and deep learning models, explaining model predictions using SHAP, and deploying the result as a web interface. The methodology follows seven main stages:

\begin{enumerate}
    \item Dataset collection and description
    \item Data cleaning and preprocessing
    \item Feature categorization and encoding
    \item Feature selection: Chi-square analysis and backward elimination
    \item Machine learning and deep learning model comparison (15 models)
    \item SHAP explainability analysis
    \item Risk factor analysis using correlation, Kendall's tau, and within-category feature importance
\end{enumerate}

Each stage is explained in order in the sections below.

\subsection{Target Variable}
\label{ch3-subsec-target}

The primary target variable used in this thesis is \textbf{EPDS Result}, a three-class categorical label derived from the EPDS Score. It classifies each mother into one of three risk categories:

\begin{equation}
\label{ch3-eqn-epdsresult}
\text{EPDS Result} =
\begin{cases}
\text{Low}    & \text{if EPDS Score} \in [0, 9] \\
\text{Medium} & \text{if EPDS Score} \in [10, 12] \\
\text{High}   & \text{if EPDS Score} \in [13, 30]
\end{cases}
\end{equation}

A score of 13 or higher on the EPDS indicates that the mother is at high risk for PPD; this is the standard clinical cut-off \cite{cox1987edinburgh}. The Medium band (10--12) is a clinical watch zone: these mothers are at elevated risk and require close monitoring even if they fall just below the full screening threshold. The Low band (0--9) represents mothers who are not currently at significant risk.

During data cleaning, 43 out of 800 rows were found to have a mismatch between the EPDS Score and the EPDS Result label in the original dataset. These were corrected by recomputing the EPDS Result directly from the EPDS Score using the cut-off points in Equation~\ref{ch3-eqn-epdsresult}.

The \textbf{PHQ-9 score} is used as a secondary reference measure. The PHQ-9 severity bands are defined as shown in Table~\ref{ch3-tbl-phq9}.

\section{Data Cleaning and Preprocessing}
\label{ch3-sec-cleaning}
% --------------------------------------------------------

The raw dataset contained several inconsistencies and data quality issues that needed to be fixed before any analysis could be done. All cleaning steps were applied in order and the final cleaned dataset was saved as \texttt{PPD\_data\_updated\_v34.csv}.

\subsection{Column Renaming and Text Standardisation}

Some column names had typos. For example, ``Recieved Support'' was renamed to ``Received Support''. All column names were stripped of extra whitespace. For all text-type (object) columns, values were also stripped of extra spaces and leading/trailing characters.

\subsection{Category Value Fixes}

Many categorical columns had inconsistent values caused by different spellings of the same category. These were fixed one by one:

\begin{itemize}
    \item \textbf{Education Level:} Different spellings of the same education category (e.g., ``S.S.C'' and ``SSC'') were standardised to one form.
    \item \textbf{Husband's education level:} Same type of spelling inconsistencies were corrected.
    \item \textbf{Total children:} The value ``More than two'' was renamed to ``More than Two'' for consistent capitalisation.
    \item \textbf{History of pregnancy loss:} ``Still-born delivery'' was corrected to ``Still-born Delivery''.
    \item \textbf{Disease before pregnancy:} One row had the value \texttt{`1.2'}, which is clearly a data entry error. This was replaced with \texttt{NaN}.
    \item \textbf{Occupation columns:} ``House wife'' (with a space) was standardised to ``Housewife'' in both the ``Occupation before latest pregnancy'' and ``Occupation After Your Latest Childbirth'' columns.
    \item \textbf{Other columns:} A batch \texttt{df.replace()} operation fixed remaining inconsistent labels across multiple columns.
    \item \textbf{Column name and value stripping:} All column names and string values were stripped of any extra whitespace.
\end{itemize}

\subsection{Duplicate Check}

After all value fixes, the dataset was checked for duplicate rows:

\section{Feature Selection: Chi-Square Analysis and Backward Elimination}
\label{ch3-sec-featuresel}
% --------------------------------------------------------

A Chi-square feature ranking followed by backward elimination was applied to identify the most predictive subset of questionnaire items for the EPDS Result target. This is a key novelty of this thesis: it identifies which specific EPDS and PHQ-9 items are most informative, reducing the full set of 65 candidate features to a compact and optimal 17-feature subset.

\subsection{Chi-Square Feature Ranking}

Chi-square ($\chi^2$) tests were computed between each of the 65 input features (all columns except Target/Score) and the EPDS Result target:

\begin{lstlisting}[language=Python, caption={Chi-square ranking of all features.}]
from sklearn.feature_selection import chi2, SelectKBest

X = df_encoded.drop(columns=['EPDS Result', 'EPDS Score',
                              'PHQ9 Score', 'PHQ9 Result', 'PPD_binary'])
y = df_encoded['EPDS Result']

selector = SelectKBest(chi2, k='all')
selector.fit(X, y)

chi2_df = pd.DataFrame({
    'Feature': X.columns,
    'Chi2 Score': selector.scores_,
    'P-Value': selector.pvalues_
}).sort_values('Chi2 Score', ascending=False)
\end{lstlisting}

The Chi-square analysis ranked all 65 features by their association with the EPDS Result target. EPDS questionnaire items (such as ``You have felt sad or miserable'', ``You have been so unhappy that you have been crying'') received the highest Chi-square scores, indicating they carry the most information about PPD risk classification. Safe background features like ``Occupation before latest pregnancy'' and ``Received Support'' ranked much lower but were retained as candidates for the backward elimination.

\subsection{Backward Elimination with Random Forest and Gradient Boosting}

A backward elimination experiment was then run. Starting from all 65 features, the feature with the lowest Chi-square score was removed one at a time. At each step, both a \textbf{Random Forest} and a \textbf{Gradient Boosting} model were trained and tested using 5-fold cross-validation on the EPDS Result target. The use of two models ensures the feature selection result is not dependent on any single algorithm. This process identified that the best cross-validation accuracy was reached when \textbf{17 features} remained (at elimination step 48 out of 64 total possible steps):

\begin{itemize}
    \item \textbf{Best CV accuracy: 0.9262 ($\pm$ 0.0072)} (Gradient Boosting)
    \item \textbf{Best F1 score (macro): approximately 0.91}
    \item \textbf{Features remaining: 17}
\end{itemize}

\subsection{The 17 Selected Features}

When the 17 optimal features were examined, \textbf{all 17 were EPDS or PHQ-9 questionnaire items}: 10 EPDS items and 7 PHQ-9 items. This finding confirms that the questionnaire items are the most informative features for PPD risk classification. The Chi-square backward elimination has identified the specific subset of screening items that, together, give the best predictive performance with the fewest features.

The 17 selected features include items such as:
\begin{itemize}
    \item ``You have been so unhappy that you have been crying'' (EPDS)
    \item ``You have felt scared or panicky for no good reason'' (EPDS)
    \item ``You have felt sad or miserable'' (EPDS)
    \item ``Feeling down, depressed, or hopeless'' (PHQ-9)
    \item ``You have been able to laugh and see the funny side of things'' (EPDS)
    \item ``Thoughts that you would be better off dead, or of hurting yourself'' (PHQ-9)
    \item (and 11 more EPDS/PHQ-9 items)
\end{itemize}

These 17 items are the validated input feature set for the main model comparison and SHAP analysis in this thesis. The full list is saved in \texttt{chi2\_optimal\_features.txt}.

The backward elimination also confirmed that the four background categories (Demographic, Familial, Personal Health, Neonatal Health) rank below all screening items in predictive power. These categories are tested separately in Section~\ref{ch3-subsec-category} to measure their standalone contribution.

All models were trained using \textbf{5-fold stratified cross-validation} on the \textbf{EPDS Result} target (three classes: Low, Medium, High) using the \textbf{17 selected features}.     f1 = cross_val_score(model, X, y, cv=cv, scoring='f1_macro')

\end{lstlisting}

\subsection{Evaluation Metrics}

The main evaluation metrics used are:
\begin{itemize}
    \item \textbf{Accuracy:} The proportion of correct predictions across all three EPDS Result classes.
    \item \textbf{F1 Score (macro):} The harmonic mean of precision and recall, averaged equally across all three classes.
    \item \textbf{Confusion Matrix:} Used to inspect true and false predictions for each class.
\end{itemize}

\section{SHAP Explainability Analysis}
\label{ch3-sec-shap}
% --------------------------------------------------------

After identifying Gradient Boosting as the best model, a SHAP analysis was conducted to explain which of the 17 selected questionnaire items drive predictions for each EPDS risk class (Low, Medium, High). This is Research Objective~4.

\subsection{Why SHAP?}

SHAP (SHapley Additive exPlanations) is a game-theory-based method that assigns each input feature a contribution score for a specific prediction. Unlike simple feature importance rankings, SHAP explains the direction and magnitude of each feature's effect for each individual prediction, making it possible to understand not just which features matter, but how they push predictions toward each risk class.

\subsection{Method: Permutation Explainer}

A \textbf{Permutation Explainer} was used instead of the default Tree Explainer because it works model-agnostically and is more robust for multi-class classification. The explainer was run on a sample of 300 test instances:

\begin{lstlisting}[language=Python, caption={SHAP analysis with PermutationExplainer on GB model.}]
import shap
import numpy as np

# Load 17-feature data and EPDS Result target
X_shap = df_encoded[chi2_optimal_features]
y_shap = df_encoded['EPDS Result']

# Train final GB model on all data
gb_model.fit(X_shap, y_shap)

# Run PermutationExplainer on 300 samples
explainer = shap.PermutationExplainer(
    gb_model.predict_proba,
    X_shap.sample(300, random_state=42)
)
shap_values = explainer(X_shap.sample(300, random_state=42))
# shap_values.shape: (300, 17, 3)
# 300 samples, 17 features, 3 output classes
\end{lstlisting}

The SHAP values array has shape (300, 17, 3): 300 test samples, 17 features, and 3 output classes. Each value in this array represents the contribution of a specific feature to the predicted probability of a specific EPDS class for a specific mother.

\subsection{SHAP Figures Generated}

Five SHAP figures are generated and saved:

\begin{enumerate}
    \item \textbf{Global bar chart}: Mean absolute SHAP values across all three classes, showing overall feature importance ranking.
    \item \textbf{Beeswarm plots (per class)}: One plot per EPDS Result class (Low, Medium, High), showing how each feature value (high or low) pushes predictions toward or away from that class.
    \item \textbf{Heatmap}: SHAP value matrix showing the contribution of all 17 features across all 300 test samples.
    \item \textbf{Waterfall plot}: A single-sample explanation showing how each feature contributes to one specific prediction.
    \item \textbf{Dependence plot}: Shows the relationship between the value of the most important feature and its SHAP contribution.
\end{enumerate}

\subsection{Top SHAP Features}

The global bar chart identifies the following as the top 10 features by mean absolute SHAP value (aggregated across all three classes):

\begin{enumerate}
    \item ``You have been so unhappy that you have been crying'' (EPDS, SHAP = 0.0585)
    \item ``You have felt scared or panicky for no good reason'' (EPDS, SHAP = 0.0500)
    \item ``You have felt sad or miserable'' (EPDS, SHAP = 0.0457)
    \item ``I have blamed myself unnecessarily when things went wrong'' (EPDS)
    \item ``I have been anxious or worried for no good reason'' (EPDS)
    \item ``Things have been getting on top of me'' (EPDS)
    \item ``I have had difficulty sleeping because of unhappiness'' (EPDS)
    \item Feeling down, depressed, or hopeless (PHQ-9)
    \item ``You have been able to laugh and see the funny side of things'' (EPDS)
    \item Moving or speaking so slowly (PHQ-9)
\end{enumerate}

The trained Gradient Boosting model and scaler were saved as \texttt{gb\_model.pkl} and \texttt{gb\_scaler.pkl}; the SHAP values were saved as \texttt{shap\_values.npy} and \texttt{shap\_data.pkl} for use in the web interface.

\section{Correlation Analysis}
\label{ch3-sec-correlation}
% --------------------------------------------------------

To understand how the 17 selected features relate to the EPDS depression score, three types of correlation were computed for each feature against the EPDS Score:

\begin{itemize}
    \item \textbf{Pearson correlation:} Measures linear relationship. Best for continuous, normally distributed data.
    \item \textbf{Spearman correlation:} Measures monotonic relationship. Works with ordinal data.
    \item \textbf{Kendall's tau:} Measures rank-order correlation. More robust to outliers and better for small samples.
\end{itemize}

\begin{lstlisting}[language=Python, caption={Three-way correlation analysis of selected features vs. EPDS Score.}]
from scipy.stats import kendalltau

for feature in selected_features:
    pearson = df[feature].corr(df['EPDS Score'], method='pearson')
    spearman = df[feature].corr(df['EPDS Score'], method='spearman')
    tau, p = kendalltau(df[feature], df['EPDS Score'])
    print(f"{feature}: Pearson={pearson:.3f}, Spearman={spearman:.3f},
                         Kendall={tau:.3f}")
\end{lstlisting}

\section{Within-Category Feature Importance (CELL 7)}
\label{ch3-sec-within-category}
% --------------------------------------------------------

To answer the question ``which specific features matter most inside each background category?'', a within-category feature importance analysis was done on the four background categories (Demographic, Familial, Personal Health, and Neonatal Health).

\subsection{Method}

For each category, four different importance methods were computed and then combined into a single score:

\begin{enumerate}
    \item \textbf{Random Forest importance:} The mean decrease in impurity from each feature across all trees.
    \item \textbf{XGBoost importance:} The gain-based feature importance from XGBoost.
    \item \textbf{Logistic Regression coefficients:} The absolute value of each feature's coefficient.
    \item \textbf{Mutual Information (MI):} A non-parametric measure of how much information a feature shares with the EPDS Result target.
\end{enumerate}

Each of the four scores was normalised to a 0--1 range using Min-Max scaling. The final \textbf{Combined Score} for each feature is the average of its four normalised scores:

\begin{equation}
\label{ch3-eqn-combined}
\text{Combined Score}(f) \;=\; \frac{\text{RF\_norm}(f) + \text{XGB\_norm}(f) + \text{LR\_norm}(f) + \text{MI\_norm}(f)}{4}
\end{equation}

\section{Risk Factor Analysis via Kendall's Tau (CELL 8)}
\label{ch3-sec-kendall}
% --------------------------------------------------------

The final clinically important analysis is the risk factor analysis using Kendall's tau. This answers Research Objective~3: which specific background factors are most strongly linked to PPD in Bangladeshi mothers?

\subsection{Why Kendall's Tau?}

Kendall's tau ($\tau$) is a rank-based correlation coefficient chosen because:
\begin{itemize}
    \item Survey data is often ordinal (e.g., ``Good'', ``Average'', ``Poor''), not continuous.
    \item Kendall's tau works correctly with ordinal data and does not assume a normal distribution.
    \item It is more robust to outliers and ties than Pearson or Spearman correlations.
    \item The p-value that comes with Kendall's tau tells us whether the association is statistically significant.
\end{itemize}

\subsection{Formula}

For two variables $X$ and $Y$ measured on $n$ observations, consider all $\binom{n}{2}$ pairs of observations.
A pair $(i, j)$ is called \textbf{concordant} if the orderings of $X$ and $Y$ agree (i.e., $X_i > X_j$ and $Y_i > Y_j$, or $X_i < X_j$ and $Y_i < Y_j$).
A pair is called \textbf{discordant} if the orderings disagree.

Kendall's $\tau_b$, which handles tied values correctly, is defined as:

\begin{equation}
\label{ch3-eqn-kendall}
\tau_b \;=\; \frac{n_c - n_d}{\sqrt{\bigl(n_0 - n_1\bigr)\bigl(n_0 - n_2\bigr)}}
\end{equation}

where:
\begin{itemize}
    \item $n_c$ = number of concordant pairs
    \item $n_d$ = number of discordant pairs
    \item $n_0 = \dfrac{n(n-1)}{2}$ = total number of pairs
    \item $n_1$ = number of pairs tied only in $X$
    \item $n_2$ = number of pairs tied only in $Y$
\end{itemize}

$\tau_b$ ranges from $-1$ (perfect disagreement in rank order) to $+1$ (perfect agreement in rank order). A value of 0 means no association. The \texttt{scipy.stats.kendalltau} function used in this thesis computes $\tau_b$ and also returns the two-sided $p$-value for the null hypothesis that $\tau = 0$.

\subsection{Method}

For each feature in the four background categories, Kendall's tau was computed against the continuous EPDS Score:

\begin{lstlisting}[language=Python, caption={Kendall's tau risk factor analysis across 4 background categories.}]
from scipy.stats import kendalltau

TARGET_CATS = ['Demographic', 'Familial', 'Personal Health', 'Neonatal Health']
results = []

for cat in TARGET_CATS:
    cat_features = [f for f in features if feature_categories[f] == cat]
    for feature in cat_features:
        tau_score, p_score = kendalltau(df[feature], df['EPDS Score'])
        results.append({
            'Category': cat,
            'Feature': feature,
            'Kendall_tau_vs_Score': tau_score,
            'p_value_vs_Score': p_score,
        })

risk_df = pd.DataFrame(results).sort_values(
    'Kendall_tau_vs_Score', key=abs, ascending=False)

risk_df.to_csv('risk_factor_kendall_tau.csv', index=False)
\end{lstlisting}

\subsection{Interpretation of Results}

\begin{itemize}
    \item \textbf{Positive $\tau$:} As the feature value increases, the EPDS Score also tends to increase --- a \textbf{risk factor}.
    \item \textbf{Negative $\tau$:} As the feature value increases, the EPDS Score tends to decrease --- a \textbf{protective factor}.
    \item \textbf{Magnitude of $|\tau|$:} Larger values mean a stronger association.
    \item \textbf{p-value:} Values below 0.05 are considered statistically significant.
\end{itemize}

\section{Summary}
\label{ch3-sec-summary}
% --------------------------------------------------------

This chapter described the full methodology of this thesis. The dataset of 800 Bangladeshi mothers was cleaned in multiple steps. All 69 features were grouped into six categories. Chi-square feature ranking combined with backward elimination identified 17 optimal EPDS and PHQ-9 questionnaire items as the most predictive features for EPDS Result classification. Fifteen machine learning and deep learning models were compared on these 17 features using 5-fold cross-validation on the EPDS Result target (Low, Medium, High), with Gradient Boosting achieving the highest accuracy of 0.926. SHAP analysis using a Permutation Explainer identified which of the 17 items drive predictions for each risk class. The four background categories were tested separately for comparison. The risk factor analysis used Kendall's tau to find the most statistically significant background predictors of PPD. A web interface was built to deploy the trained model. The next chapter presents the results of all these analyses.
